# LIFT Family

GitHub Pages 部署用檔案。

建議 Repository 名稱：`lift-family`

GitHub Pages 設定：
- Settings → Pages
- Build and deployment → Deploy from a branch
- Branch：`main`
- Folder：`/(root)`

預計網址：
`https://carolinechu1993.github.io/lift-family/`

注意：
- 之後更新請覆蓋同一個 repository，不要另建新 repo。
- 正式使用前先確認網址固定，再設定 Firebase Authorized Domains。
- 不要把私人備份 JSON、服務帳戶私鑰或 Firebase admin 憑證上傳到 GitHub。
